# Lab Sheet 9 — PHP and MySQL Solutions

This project covers all 20 Lab Sheet 9 tasks: MySQL schema, PDO connection,
registration/login, sessions, product CRUD, pagination, filtering, sorting,
image upload, SQL injection/XSS prevention, remember-me cookie, shopping cart,
transactional checkout, and AJAX live search.

## Setup
1. Install PHP 8.1+, MySQL/MariaDB, and Apache (XAMPP is suitable).
2. Import `database/schema.sql` in phpMyAdmin.
3. Set database credentials in `config/config.php`.
4. Put the folder in your Apache document root and open `public/`.
5. Register a user and log in.

See the code comments and the main project README in the combined project for further setup/security notes.
